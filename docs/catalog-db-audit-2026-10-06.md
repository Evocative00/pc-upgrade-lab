# 로컬 DB 점검 기록 — 2026-10-06

로컬 MySQL 8.4.11의 `pc_upgrade_lab`을 읽기 전용으로 점검했다. 점검 시 Flyway V1–V11은 성공 상태였다. 개인정보·접속 비밀번호·원본 PC 내용은 이 문서에 저장하지 않는다. 집계는 점검 당시 값이며 이후 DB 변경에 따라 달라질 수 있다.

후속 작업으로 2026-10-06 21:50(한국 시간), 사용자의 승인에 따라 V12와 22종의 현재 상품가를 실제 MySQL에 반영했다. [현재가 반영 기록](catalog-current-prices.md#첫-매핑과-수집)을 참고한다. 아래 집계와 읽기 전용 점검 결과는 감사 당시 기록으로 유지한다.

## 구조와 저장 현황

업무 테이블은 17개, 열은 154개다. 카탈로그는 제품 기본 행, 기준가격, 출처와 종류별 제원으로 나뉜다. CPU 메모리 규격 및 메인보드 CPU 지원 정보는 별도 관계 테이블을 사용한다. PC와 부품은 카탈로그 연결 여부와 별개로 저장되고 회원·소셜 계정이 소유자를 정한다.

| 구분 | 점검 당시 행 수 |
| --- | ---: |
| 카탈로그 제품 / 기준가격 | 각 300 |
| 제품 출처 | 839 (BuildCores 300, 제조사 539) |
| CPU / 메인보드 / RAM / GPU / 모니터 제원 | 70 / 70 / 60 / 80 / 20 |
| GPU 전원 커넥터 | 90 |
| CPU 메모리 지원 / 지원 규격 관계 | 70 / 101 |
| 메인보드 CPU 지원 프로필 / 지원 행 | 70 / 1,807 |
| PC / PC 부품 | 1 / 14 |
| 회원 / 소셜 계정 | 각 3 |

모든 제품에 종류에 맞는 제원과 기준가격 행이 존재했다. FK 고아 행, 종류와 제원의 불일치, 정규화한 제조사·모델 중복, 비어 있는 문자열, 음수 수치, 점검한 JSON 수치·단위 오류는 발견되지 않았다. 154개 열 중 51개에는 NULL이 있었다. NULL은 미확인·해당 없음일 수 있으므로 모두 오류로 보지 않는다.

## 가격과 제품 식별

- 제품 300개의 기준가격은 모두 `UNCONFIRMED`, 금액은 NULL이었다. 제품은 모두 `UNVERIFIED`, 비활성 상태다.
- 장기 기준가격에는 기간·산정법·근거용 필드가 있으나, 현재 구매가 수집 및 6개월 기준가격 계산은 구현되어 있지 않았다.
- 원본에 판매처 항목 9,137개가 277개 제품에 있었지만 한국(`kr`) 항목은 없었다. 국내 현재가로 그대로 사용할 수 없다.
- 서로 다른 제품에 걸친 판매처 키 충돌 11개를 발견했다. 예를 들어 같은 Walmart ID가 i5-12400과 i5-12400F에, 같은 Geizhals ID가 CPU와 여러 GPU에 연결되어 있었다. 원본의 검증 플래그만으로 가격 수집 대상을 확정하면 안 된다.
- 원본 식별자 이상 후보는 14개였으며 CPU 박스 부품번호 불일치와 잘린 RAM 식별자 등이 포함됐다.
- 부품번호가 없는 제품은 94개다(CPU 15, 메인보드 39, GPU 40). 이름만으로 정확한 판매 SKU를 확정하지 않는다.

이 때문에 현재가는 검토한 국내 판매 SKU 매핑과 관측 이력을 별도로 추가하는 방식으로 진행한다. [현재가 규격과 작업 순서](catalog-current-prices.md)를 참고한다.

## 우선 보완할 제원

| 종류 | 누락된 주요 필드 |
| --- | --- |
| GPU 80종 | PCIe 커넥터 레인 수 66, 실제 동작 레인 수 41, 사용 슬롯 수 67, 공표 전력 19, 높이·두께 각각 9 |
| RAM 60종 | 높이 48, 핀 수 22, ECC 여부 17, 전압 1 |
| 메인보드 70종 | ECC 지원 여부 25 |
| CPU 메모리 지원 70종 | 최대 용량 13, 채널 수 6 |
| 모니터 20종 | 전력 19, 오버클럭 주사율 15 |

GPU·RAM의 크기와 슬롯, 전력 관련 필드부터 보완하면 실제 장착 및 파워 선택 판단에 도움이 된다. 모니터 오버클럭 등은 해당 기능이 없는 경우와 미확인을 구분해 검토한다.

메인보드 CPU 지원 1,807행 중 32행은 `UNVERIFIED`였다(ASRock B760M Pro RS 12, B550M Pro4 8, B650M Pro RS 5, Gigabyte B650 GAMING X AX 7). BIOS 최소 버전은 `UNKNOWN` 63행, `ALL` 41행, 버전 지정 1,703행이었다. 동일 보드·CPU 쌍은 1,638개이며 나머지는 지원 세부 조건을 포함해 확인해야 한다. 미검증 지원을 확정 호환으로 표시하지 않는다.

STORAGE·PSU·CASE·COOLER는 부품 입력 종류에 존재하지만 카탈로그 제품·전용 제원 테이블은 아직 없다. 이 범위의 가격을 채우려면 제품 구조부터 확장해야 한다.

## PC와 회원

저장된 PC 부품 14개 중 카탈로그 연결은 1개, 미연결은 13개였다. `UNMATCHED`는 수집 오류를 뜻하지 않는다. 기존 PC 1개는 소유자 `user_id`가 NULL인 레거시 데이터여서 회원별 PC 조회 흐름과 함께 별도로 정리해야 한다. 회원 이메일 NULL 2개는 소셜 계정 정책과 함께 판단할 값이며, 빈 이메일 문자열 오류는 아니었다.

이번 점검과 코드 준비에서 실제 DB 마이그레이션·가격 입력·seed·초기화는 실행하지 않았다. 일반 H2 테스트 결과는 실제 MySQL 적용 결과와 구분한다.
