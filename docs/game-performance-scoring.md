# 게임 요구 사양의 CPU·GPU 수치 비교 준비

Issue #35의 게임 5종 기본 진단에 점수 비교를 나중에 붙일 수 있도록 한 내부 설계다.
현재 저장소에는 재사용 권한이 확인된 CPU·GPU 모델별 점수 자료가 **없다**. 따라서 실제 화면은
다른 모델을 여전히 `확인 불가`로 표시하며, 수치·성능 우열·예상 FPS를 만들어 내지 않는다.

## 비교 규칙

1. 현재 부품과 게임 제작사의 최소·권장 예시 모델을 정확한 모델명에 연결한다.
2. **같은 발행처, 같은 시험 지표, 같은 시험판**의 양수 점수만 비교한다.
3. 요구 사양에 대체 모델이 여러 개 적혀 있으면, 모든 대체 모델의 점수가 있을 때에만
   그중 점수가 가장 낮은 모델을 비교 기준으로 삼는다(공식 예시 중 하나를 만족하는 구조).
4. `내 점수 / 예시 모델 점수`의 비율을 표시할 수 있다. 1 이상은 `점수 기준 이상`,
   1 미만은 `점수 기준 미만`일 뿐, **게임 실행 가능/불가 판정이 아니다**.
5. CPU 싱글 스레드, CPU 멀티 스레드, GPU 3D 점수는 각각 다른 지표다. 서로 섞거나
   임의 가중치로 하나의 게임 점수를 만들지 않는다. 공식 사양이 제품군만 적은 경우에도
   기준 모델을 임의로 고르지 않는다.
6. 자료의 모델·점수·출처·시험판이 빠졌거나 서로 충돌하면 `확인 불가`다.

순수 비교 함수는 `frontend/src/features/planner/benchmarkComparison.ts`에 있다.
테스트의 점수는 **가상 fixture**이며 실제 제품 점수가 아니다. UI에 수치 결과를 연결하려면
먼저 자료 이용권과 정확한 모델 대응표를 검증해야 한다.

## 후보 자료와 이용 조건

- [PassMark 모델별 CPU·GPU 점수](https://www.passmark.com/services/market-analysis.php):
  공개 페이지에서 개별 점수를 볼 수 있지만 모델별 데이터 묶음은 별도 라이선스 대상이다.
  이용 조건이 합의되기 전에는 점수를 복사하거나 자동 수집하여 저장소에 넣지 않는다.
- [UL Benchmarks 성능 API](https://support.benchmarks.ul.com/support/solutions/articles/44002238427-api-documentation):
  CPU·GPU 구성에서 게임 성능까지 추정하는 계약형 서비스다. 접근 권한과 계약 범위 확인 전에는
  호출이나 응답 값을 전제로 기능 완료를 주장하지 않는다. 별도 Issue #37에서 다룬다.

## 다음 단계의 선행 조건

- PM과 자료의 라이선스·표시/저장 범위, 모델 매칭 책임, 갱신 주기를 합의한다.
- 최소·권장 예시 모델과 실제 카탈로그/사용자 PC 모델의 점수 커버리지를 측정한다.
- 확인된 자료만 점수 비교 함수에 주입하고, 결과 화면에는 지표명·출처·시험판·확인일을 표시한다.
- 점수 비교와 게임별 FPS 예측은 분리한다. FPS는 게임·해상도·화질에서 검증한 데이터가 있어야 한다.
